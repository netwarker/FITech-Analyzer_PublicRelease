# FiTech Log Analyzer — Quick Start

1. Download the current Windows release from GitHub Releases.
2. Start FiTech Log Analyzer and read/accept the Safety & Limited-Use Agreement.
3. Choose **Activate Free 60-Day Use Online**. No name or email address is required for normal activation.
4. Complete New User Setup and select your FiTech system/handheld as accurately as possible.
5. Open a Dashboard or Basic Sensors CSV with **File → Open Log**.
6. Read **Summary / Diagnostics** first, then use Novice Charts, Troubleshooting, History, and Compare as needed.
7. Use **Help → Send Feedback** if something is incorrect, confusing, broken, or your FiTech model/handheld needs better mapping.

## Privacy

Online activation sends a derived Device Code, app version, and license-format information. Feedback is sent only after you explicitly choose **Submit Feedback Online**. Screenshots are optional. FiTech CSV logs and vehicle/profile information are OFF by default.

If online activation or feedback is unavailable, offline/manual fallback remains available through **netwarker@gmail.com**.

## Safety

Do not change tuning or repair a vehicle simply to satisfy the software. Diagnostic findings and procedures are screening/reference information and must be independently verified before acting on them.
