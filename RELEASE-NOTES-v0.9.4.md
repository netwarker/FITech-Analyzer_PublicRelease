# v0.9.4 LIMITED — ONLINE

Planned first internet-enabled limited release.

## New
- automatic 60-day online activation
- manual signed `.ftkey` import remains available as an offline fallback
- online feedback submission only after explicit user action
- local feedback ZIP/email fallback retained
- optional screenshot; FiTech CSV and vehicle/profile information remain OFF by default
- public configuration and update metadata hosted in this repository
- in-app update check

## Existing capabilities retained
- Dashboard and Basic Sensors CSV import, including supported headerless/repeated-header formats
- evidence-based diagnostics and prioritized next steps
- beginner/novice charts
- before/after comparison
- troubleshooting center
- vehicle profiles/history and actual Log/Test Date handling
- model/handheld support labels with unverified configurations clearly identified

The Windows executable will be attached to a GitHub Release after final activation/build verification.
